# Tajada Studios

Website for Tajada Studios, home of Historias de Pasta. Static, bilingual (EN/ES), served with GitHub Pages.

- `index.html` is the whole site: studio, projects, about (`#about`) and contact.
- Language toggle in the header; copy lives in the `T` object at the bottom of `index.html`.
- `favicon.svg` and the inline `#mark` symbol are the circle logo.
