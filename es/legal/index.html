Aviso legal y privacidad

Quién está detrás

Tajada Studios es un proyecto de Francisco (Kiko) Tajada, con base en Suiza. Contacto: kiko@tajadastudios.com.

Qué datos recoge esta web

Ninguno por sí misma. No hay cookies, ni analítica, ni scripts de seguimiento. Las fuentes se sirven desde esta web, no desde terceros. Si cambias de idioma, la elección se guarda solo en tu navegador.

Alojamiento

La web está alojada en GitHub Pages. GitHub puede registrar datos técnicos como direcciones IP por seguridad y operación; consulta la declaración de privacidad de GitHub.

Si nos escribes

Usamos tu email solo para responderte y lo borramos cuando ya no hace falta. Puedes preguntar qué datos tenemos tuyos o pedir que los borremos en la dirección de arriba.

Enlaces a otras webs

Los enlaces a YouTube, Instagram, TikTok y otras webs llevan a servicios con sus propias políticas de privacidad.
